# 📌 Проект по работе с категоризацией товаров

Проект посвящен созданию структуры хранения и обработки информации о продуктах и категориях с использованием парадигмы объектно-ориентированного программирования (ООП). Реализованы две основные сущности: товары и категории. 

## ✅ Цели проекта

Целью данного домашнего задания является закрепление основ объектно-ориентированного подхода, знакомство с управлением проектами через GitFlow, организацией рабочего пространства с помощью virtualenv (через Poetry), и улучшением качества кода посредством линтеров и форматеров.


## ⚙️ Функциональности проекта

### 👉 Классы `Product` и `Category`

Реализованы классы `Product` и `Category` с необходимыми свойствами.

#### Поля класса `Product`:
- Название (`name`)
- Описание (`description`)
- Цена (`price`)
- Количество в наличии (`quantity`)

#### Поля класса `Category`:
- Название (`name`)
- Описание (`description`)
- Список товаров (`products`)


### 👉 Юнит-тесты
Созданы юнит-тесты для проверки правильности работы классов и методов, а именно 
- Корректности инициализации объектов классов `Category` и `Product`
- Правильности подсчета количества продуктов
- Правильности подсчета количества категорий

###  Загрузка данных о товарах и категориях из файла JSON (опционально)
Реализован специальный метод, который читает содержимое файла и формирует объекты соответствующих классов.
